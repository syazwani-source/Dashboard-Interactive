# Lens Studio — Photography Dashboard

Dashboard interaktif bertema fotografi dengan gaya minimalist, neutral/pastel dan ilustrasi kamera Nikon-inspired.

## Features
- Overview fotografi
- Projek terkini
- Checklist tugasan interaktif
- Modal New Project
- Responsive desktop/mobile layout
- Minimalist camera illustration

Dibina sebagai static web app yang boleh terus dihoskan di Vercel.
